# Elemental System
- Each player can have 1-2 types.
- Each type is based off of a color (R, G, B, Y, C, M, O, P).
- Each type has 2 passive effects, one positive and one negative.
- Using an attack that matches your secondary type twice in a row will swap your primary and secondary typing.
- Using an attack that matches neither of your types twice in a row will replace your secondary typing.
- Certain type combos will cause a reaction, forming a new type.
    - This includes the player's primary and secondary types.

Examples:

Attacker type = Red 
Defender type = Blue
Attack is Red and Melee
Result: Both players become Magenta

Attacker type = Red
Defender type = Blue
Attack is Red and Ranged
Result: Defender becomes Magenta, Attack stays Red

Attacker type = Red
Defender type = Blue and Red
Attack is Red and Ranged
Result: Defender becomes Magenta and Red (Red + Blue = Magenta, Red + Red = no reaction)

Attacker type = Red
Defender type = Blue and Cyan 
Attack is Red and Ranged
Result: Defender becomes Magenta and Cyan (Red + Blue = Magenta, Red + Cyan = no reaction). Defender then becomes Blue (Magenta + Cyan = Blue). The Defender has also lost their secondary type.

Attacker type = Red and Magenta
Defender type = Blue and Yellow
Attack is Green and Melee
Result: Defender becomes Cyan and Yellow (G+B=C, Y+G=n), then Green (C+Y=G). Attacker becomes Yellow and Magenta (G+R=Y, G+M=n), then Red (Y+M=R).
