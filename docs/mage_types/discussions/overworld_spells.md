# The Concept
We're gonna look at a spectrum:
Simple <--> Complex

This system should allow the player to remove obstacles from out of their way. More complex systems should allow for more creative and interesting solutions. But we're not trying to make the next Portal or w/e. This is meant to be a silly little transmutation game.

A `Simple` system would be something like Pokemon, where each `Lock` has a `Key`. 
- Small tree => Cut
- Cracked rock => Rock smash

I'm trying to design a system with more depth, but I don't think that's actually the play here. I should aim for a more simple system, with the aim to tie it into the preexisting systems (Resistances, Affinity, Transmutation).

Thematically, this claymation aesthetic would allow for a more sandbox-y approach, but I don't really want to commit to that.
